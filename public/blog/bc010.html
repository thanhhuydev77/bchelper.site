Mastering RDLC: Fixing Report Layouts Without Using Footers

Background

In our previous post (the 2-Column Report layout), we successfully optimized a warehouse shipment report to split data across parallel columns. While the layout looked great to the warehouse staff, real-world deployment brought a new operational layout challenge.

The Problem The warehouse team requires the Notes section to be anchored strictly at the bottom of the printed page. If the table data is short, standard body elements shrink upward, misaligning the notes and breaking layout uniformity on predefined paperwork.

Evaluation of Solutions

To fix the layout height dynamically, we weighed three possible approaches:

  • Option 1: Use Report Footer (Rejected)
    Report footers are designed for static global data. If requirements evolve and we need to pass data-driven dynamic notes from specific Warehouse Shipment headers, forcing dataset values into a footer requires dangerous workarounds.
  • Option 2: Create Empty Rows in AL (Rejected)
    Generating fake spacer lines in the dataset bloats memory usage and forces unnecessary rendering loops. This introduces severe technical debt and harms system performance.
  • Option 3: Embedded Lists inside a Fixed Rectangle (Selected)
    By embedding our structural list into an explicitly sized, non-growing Rectangle container inside the row group, we achieve a locked body size natively. No dataset bloat, no rigid footer restrictions.

Technical Implementation

SSRS RDLC Report Rectangle
Step 1: Create New RDLC Layout

In the Rendering section of your report, add a new layout with type RDLC. Clone the old layout file, rename it, and open it in SSRS Report Designer.

Step 2: Add a New Row

Insert a clean blank row directly below your current Detail Row group. This row will host the Rectangle container.

Step 3: Insert the Rectangle Container

Resize the newly created row to the desired height, then insert a Rectangle component spanning across both left and right columns.

Step 4: Re-anchor the List Control

Cut your existing tabular data List control and Paste it inside the Rectangle container. Drag and align it to the exact top-left corner of the container.

Step 5: Cleanup

Safely delete the old, uncontainerized table row structure from the design tree to keep the layout clean.

Step 6: Math-Driven Height Calculations

To lock the canvas at a strict maximum of 10 rows without vertical growth, configure the following in the Properties window:

  • Set the internal Row Height to 0.3 inches.
  • Set the Rectangle Height to 3.0 inches (10 rows × 0.3 in).
Step 7: Compile and Deploy

Save your updated RDLC file and compile the AL extension to publish the changes to your environment.

Testing
